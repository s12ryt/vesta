# Vesta — 專案檔案/目錄依賴與用途表 (項目表)

> 記錄專案各檔案與資料夾的用途，以及彼此依賴關係。隨變更同步更新。

## 頂層結構

| 路徑 | 用途 |
|------|------|
| `CMakeLists.txt` | 建置定義。**明確列出來源檔（非 glob）**；MSVC 啟用 `/utf-8`；含多個測試可執行檔（如 `vesta_menu_render_test`） |
| `CMakePresets.json` | 建置 preset（如 `release`） |
| `src/` | 主程式原始碼（見下） |
| `tests/` | ctest 測試；未引用 `render::localization` 列舉或 `count` |
| `configs/` | 設定檔範本：`full-legit.cfg`、`legit.cfg`、`semi-rage.cfg`（JSON，含 `language` 欄位） |
| `lua/` | Lua 腳本與文件：`scripts/`、`docs/en/*`（英文）、`docs/*`、`packages/web-radar` |
| `website/` | 官方網站（英文） |
| `.github/` | CI workflows、issue 範本、release notes、`assets/` |
| `cmake/patches` | 第三方依賴修補 |
| `agent/` | 本專案紀錄（deep_todos / 項目表 / memory） |
| `README.md` / `LICENSE` / `NOTICE` / `THIRD_PARTY_NOTICES.md` | 說明與授權（Apache 2.0） |

| `src/features/` | 功能：`aimbot`、`legitbot`、`misc`（含 `nade_helper.cpp`，使用 `tr()`）、`trigger`、`visuals`（`bomb.cpp`/`projectile.cpp` 使用 HUD 字型） |
| `src/render/` | 渲染 |
| `src/render/menu/` | 選單 UI：`layout.cpp`、`widgets.cpp`、`misc_page.cpp`、`visual_editor.cpp`、`localization.{hpp,cpp}` |
| `src/render/overlay/` | 覆蓋層：`overlay.{hpp,cpp}`（初始化 ImGui/DX11 與**字型**）、`hud.cpp`（水印/觀戰者列表/活動綁定，使用 `menu_*` 字型） |
| `src/render/chams/` | 人物模型透視 |
| `src/render/draw.hpp` | `zdraw` 繪圖與**字型 API** |
| `src/resources/` | 內嵌資源：`fonts/`（`notosans_medium.hpp` 428796 bytes、`weapons.hpp`）、`images`、`nades`、`sounds` |
| `src/scripting/` | Lua 5.4 沙箱 API |
| `src/simulation/` | 遊戲狀態模擬/預測 |
| `src/system/` | 系統整合 |
| `src/stdafx.*` | 預編譯標頭 |

## 字型與 CJK 說明

- `zdraw::font` 欄位：`im_font`、`plain_im_font`、`font_size`。
- 字型 API（`src/render/draw.hpp`）：
  - `add_font_from_memory(data, size_bytes, size_pixels, atlas_w, atlas_h, profile, glyph_ranges=nullptr)`
  - `add_font_from_file(path, size_pixels, atlas_w, atlas_h, glyph_ranges=nullptr, profile=smooth)`
  - `merge_font_from_file(destination, path, size_pixels, profile, preload_ranges=nullptr)`（設 `MergeMode`，需 `destination->im_font`）
  - `atlas_w/atlas_h` 參數實際未使用，atlas 於 `Build()` 自動調整大小。
- 內嵌 Noto Sans（`notosans_medium`）與系統 Segoe UI 均**無 CJK 字形**；使用中文前必須合併中文字型（見 T-001）。
- 供應商 ImGui 提供 `GetGlyphRangesChineseSimplifiedCommon()`（約 2500 簡體常用字，**不含多數繁體字形**）與 `GetGlyphRangesChineseFull()`（完整但極大）；亦提供 `ImFontGlyphRangesBuilder`（`AddText`/`AddRanges`/`BuildRanges`）。
- [T-002] 因簡體常用範圍不含繁體字形、完整範圍又過大，改用 `ImFontGlyphRangesBuilder` 將 `localization::cjk_glyph_text()`（本 UI 所有簡繁中文譯文串接）+ `GetGlyphRangesChineseSimplifiedCommon()` 合併成精準範圍，再交 `merge_font_from_file` 合併。
